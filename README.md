# Qwen Sidebar Extension

Qwen Sidebar is a lightweight Chrome extension that brings the Qwen.ai chat interface directly into a convenient sidebar. With a single right-click, you can access Qwen chat on any webpage—no more switching tabs or losing context.

## Features

- **Sidebar Chat**: Opens Qwen.ai in a persistent sidebar for seamless multitasking.
- **Context Menu Integration**: Right-click anywhere on a page to launch the sidebar (feature in progress).
- **Minimal & Efficient**: Designed to stay out of your way until you need it.

## How It Works

1. **Install the Extension** in Chrome.
2. **Right-click** on any webpage and select "Open Qwen Sidebar" (coming soon).
3. Chat with Qwen.ai without leaving your current page.
